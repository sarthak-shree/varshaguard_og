# Bihar Live — Patna and Muzaffarpur

The Bihar Live route (`/bihar-live.html`) uses the same VarshaGuard visual theme, logo, and AI assistant as the main dashboard, while keeping its Bihar-specific district selector, map, data-status view, and source information.

## Coverage

- Patna and Muzaffarpur, Bihar
- Optional browser location display on the map

## Status and use

This dashboard is a prototype. Its current mode is shown on screen; synthetic demo values are not live observations, and rainfall estimates are not flood probabilities. Follow official IMD, CWC, and local disaster-management alerts for safety decisions.

The AI assistant uses the dashboard context and should explain only the values and limitations shown here.

## Source and setup

The application source and setup instructions are in [sarthak-shree/varshaguard_og](https://github.com/sarthak-shree/varshaguard_og). Keep API keys in environment variables; do not commit `.env` files.
