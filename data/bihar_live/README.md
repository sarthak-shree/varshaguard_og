# Bihar Live data

This directory is reserved for the isolated JalDrishti / Bihar Live prototype.

Do not mix these assets with the existing backend/bihar_v1 historical-model pipeline.

## Planned modes

- DATA_MODE=synthetic — deterministic demo data only.
- DATA_MODE=real — real source adapters only; missing/invalid real data is a hard failure.

The full adapter contracts will be added in the next Bihar Live build phase.
